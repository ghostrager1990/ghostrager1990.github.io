# Stanorius Software | Projects & Desktop Utilities

Welcome to the central repository and landing page for my open-source tools, system utilities, and software experiments. The primary focus is on building lightweight, performant C#/.NET Windows desktop applications designed for performance tuning, workflow automation, and resource management.

---

## 🛠 Featured Public Projects

### 1. [NetPulseShaper](https://github.com/ghostrager1990/NetPulseShaper)
* **Category:** Network & Traffic Shaping
* **Stack:** C#, .NET
* **Overview:** A lightweight Windows utility focused on network interface monitoring and connection optimization. It allows developers and gamers to monitor throughput, identify latency spikes, and fine-tune connection behavior for sensitive workloads.

---

### 2. [PhotonTray](https://github.com/ghostrager1990/PhotonTray)
* **Category:** System Tray & Desktop Management
* **Stack:** C#, Windows Forms / WPF
* **Overview:** A zero-friction background system tray utility designed for fast access to screen controls, display adjustments, and quick-toggle desktop tools without cluttering the main workspace.

---

### 3. [RAM-Cleaner-Standby-Purger](https://github.com/ghostrager1990/RAM-Cleaner-Standby-Purger)
* **Category:** Memory Management & Optimization
* **Stack:** C#, Win32 / Native APIs
* **Overview:** A high-efficiency performance utility engineered to purge bloated Windows standby memory lists and flush working sets. Particularly useful for heavy gaming sessions, 3D rendering, and video editing environments where Windows cache bloat causes stutter or micro-freezes.

---

### 4. [ShaderPurge](https://github.com/ghostrager1990/ShaderPurge)
* **Category:** GPU & Graphics Pipeline Optimization
* **Stack:** C#, .NET 9.0, WPF / WPF-UI, Windows APIs
* **Overview:** A modern, hardware-aware desktop utility designed to scan, manage, and deep-clean corrupt or bloated GPU driver caches (AMD, NVIDIA, Intel), Direct3D pipeline objects, and game launcher caches. Built to eliminate frametime hitching, texture pop-in, and micro-stutter in demanding 3D workloads.
